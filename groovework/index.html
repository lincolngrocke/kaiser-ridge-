Your Name

Team features
Turn on if someone else works from their own device. Adds a Manager/Worker role and lets you plan and pin jobs to their phone. Leave off if it's just you.
Device Role
Manager can edit everything. Worker can clock in/out, add notes, tag time to a project step, and view the planner — but can't add or edit jobs, equipment, projects or planner blocks. It's a tidiness guardrail, not a security lock.

Manual = the job editor's order. Last used = the average order you ticked tasks off across your last 3 times doing this job. Typical = the average across all recent times. (Display only — doesn’t change the saved tasks; switch back to Manual any time to revert.)
Google Sheet Web App URL
To enable Google Sheets sync, deploy a Google Apps Script as a Web App from your spreadsheet. See the setup guide below. Once deployed, paste the URL above.
Google Maps API key
Optional — lets you tap a spot on a Google Map when dropping a pin. Create a Maps JavaScript API key in Google Cloud and restrict it to your Pages URL. Without a key, Drop Pin just uses your current GPS location.

Backup & Restore
Your jobs, tasks, guides, settings, and entries are saved only on this device. Every clock-out automatically sends a full backup to Google Drive (“KR App Backups” folder) — notes, pins, timesheets, settings, the lot. Lost or wiped phone? Install the app, set Your Name and the Apps Script URL, then tap “Restore from Drive Backup”. Manual file export still works as an extra copy.
No backup yet — tap "Export Backup" below to create one.
Storage
Notes, to-dos and timesheets live in the phone’s big store, which grows as needed — capture forever, delete nothing. Settings and the job library use a separate small store. Photos saved on-device (when Drive couldn’t be reached) still count until moved to Drive.
Share Job Library
Publish your jobs to the Sheet so other phones (e.g. Ethan's) auto-update — they'll see “New job library available” and pull it with one tap. Or pass a file manually with Export/Import below. Either way, the other device's timesheets, projects-in-progress and settings stay untouched.

Google Apps Script Setup
1. Open your Google Sheet → Extensions → Apps Script
2. Delete any existing code and paste the Apps Script from the .txt file saved alongside this app
3. Click Deploy → New deployment → Web app
4. Set "Who has access" to Anyone
5. Copy the Web App URL and paste it above
